ANDROMEDA — an ambient instrument · Dark Funk Durcal design · Polaris Sound Lab

INSTALL (Mac, Apple Silicon or Intel, macOS 11+)
1. Unzip ANDROMEDA-mac.zip.
2. Right-click "Install ANDROMEDA.command" → Open → Open.
   If macOS refuses: System Settings → Privacy & Security → scroll to "Install ANDROMEDA.command" → "Open Anyway".
   (Or in Terminal:  xattr -dr com.apple.quarantine ~/Downloads/ANDROMEDA  then double-click.)
3. Ableton Live → Settings → Plug-ins → turn on "Use VST3 Plug-in System Folders" (or Audio Units) → Rescan.
4. Browser: Plug-ins → Polaris Sound Lab → ANDROMEDA. Drop it on a MIDI track.

IN ABLETON
- Press play in Live: ANDROMEDA follows Live's tempo and bar. Without Live playing, its own PLAY button works too.
- 74 automatable parameters in banks of 8.
- To run audio through ANDROMEDA: open the plug-in's Sidechain section and pick an audio track, or INPUT · MIDI → LOAD AUDIO.
- Drag a scene or song out as MIDI (SONG & FILES → MIDI).

See KeyLab-Essential-49.md for the controller.
